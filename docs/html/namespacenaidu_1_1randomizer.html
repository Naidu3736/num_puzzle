Board naidu::randomizer::generate ( std::uint8_t dim,
const Config & config,
std::mt19937 & rng )

Genera un tablero aleatorio resoluble.

Aplica un random walk desde el estado resuelto. Garantiza que el tablero resultante es soluble (los movimientos del hueco son reversibles). Si avoid_revisits está activo, evita visitar el mismo estado dos veces durante el walk.

Parámetros
dimDimensión del tablero (3..15).
configParámetros del walk.
rngGenerador de números aleatorios.
Devuelve
Tablero resoluble aleatorio.
