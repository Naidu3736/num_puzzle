Solution naidu::solver::ida ( const Board & initial,
const Board & goal,
const Config & config = {} )

Resuelve un num-puzzle usando IDA* (Iterative Deepening A*).

Aplica el algoritmo IDA* con umbrales crecientes sobre la función de evaluación f(n) = g(n) + h(n). Garantiza encontrar solución óptima en costo si la evaluación es admisible; en caso contrario devuelve una solución subóptima.

Parámetros
initialTablero inicial.
goalTablero meta.
configLímites de nodos y profundidad.
Devuelve
Solución con la secuencia de movimientos, costo, nodos expandidos y flag found.
