Descripción detallada

Conjunto de direcciones, representado como una máscara de bits.

Cada bit del índice i indica si la dirección i-ésima está presente (ver Direction y to_index). Permite combinar y consultar movimientos legales de forma O(1) y sin asignaciones dinámicas.

Ejemplo: MoveSet s = Direction::UP | Direction::LEFT; s.contains(Direction::UP); // true s.count(); // 2 for (Direction d : s) { ... }
