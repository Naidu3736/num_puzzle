Descripción detallada

Representa un tablero de num_puzzle (puzzle deslizante) de tamaño N×N.

Almacena las fichas en un arreglo lineal de tamaño N². El valor 0 representa la casilla vacía (hueco). El tablero mantiene su propio índice del hueco para evitar búsquedas repetidas.

El almacenamiento interno es un std::array de tamaño fijo MAX_TILES, pero solo los primeros m_size elementos (N²) son válidos. Esto permite cambiar de dimensión en tiempo de ejecución sin asignaciones dinámicas.

Dimensiones soportadas: 3×3 hasta 15×15.
